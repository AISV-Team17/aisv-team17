# ADR-016: 서비스 언어는 영어로 하고 한국어는 확장 실험으로 둔다

| 항목 | 값 |
| --- | --- |
| **상태** | 수락됨 |
| **날짜** | 2026-10-20 |
| **작성자** | `BOTH` |
| **검토자** | `AI-SVC`, `AI-MDL` |

---

## 컨텍스트

1단계 탐지 모델의 학습 데이터(RAGTruth), 기준선 모델(LettuceDetect), 응답 임베딩 모델(all-MiniLM-L6-v2)이 모두 영어로 검증되어 있다. 반면 발표 청중은 한국어 사용자이고, 한국어 환각 탐지는 연구 기여가 될 여지가 있다.

## 결정 근거

- 1단계 탐지 모델이 검증된 조건에서 실험·시연할 수 있는지.
- 실험 결과의 타당성(학습 분포와 평가 분포의 일치).
- 시연 설득력.
- 추가 연구 기여 여지.

## 고려한 옵션들

- 옵션 1: 전부 한국어
- 옵션 2: 전부 영어
- 옵션 3: 영어로 본 실험, 한국어 소규모 확장 실험, 콘솔 UI 문구만 한국어

## 결정

옵션 3 **영어 본 실험 + 한국어 확장**을 선택한다. 한국어로 시연하면 성능이 검증되지 않은 상태의 탐지 모델로 결과를 보여 주게 되어 실험과 시연의 신뢰도가 함께 떨어진다. 감시 대상 서비스와 데이터는 영어로 두되, 콘솔 UI 문구는 한국어로 작성해 발표 가독성을 확보한다. 한국어 탐지는 여력이 있을 때 소규모 검증셋으로 별도 측정하는 확장 실험으로 남긴다.

## 결과

**긍정적**

- 탐지 모델의 학습 분포와 실험 분포가 일치해 결과 해석이 명확하다.
- 임베딩 모델을 영어 전용 소형 모델로 고정해 메모리를 아낄 수 있다.
- 콘솔 문구가 한국어라 발표 시 설명 부담이 적다.

**부정적**

- 시연에서 응답 내용이 영어라 청중이 정오를 판단하는 데 한 단계가 더 필요하다(시연용 코퍼스를 쉬운 기술 문서로 고르는 것으로 완화).
- 한국어 기여는 이번 범위에서 증명되지 않는다.

**후속 작업**

- 시연용 영어 오픈 라이선스 기술 문서 코퍼스 확정 (미결 A-4)
- 한국어 확장 실험 시 임베딩 모델 교체 인터페이스 확인

---

## 옵션별 장단점

### 옵션 1 — 전부 한국어

- 장점: 시연 이해도가 가장 높다.
- 단점: 학습 데이터·기준선·임베딩이 모두 영어라 탐지 성능이 미검증 상태가 된다.

### 옵션 2 — 전부 영어

- 장점: 실험 타당성이 가장 높다.
- 단점: 콘솔 문구까지 영어면 발표 전달력이 떨어진다.

### 옵션 3 — 영어 본 실험 + 한국어 확장 (채택)

- 장점: 타당성과 전달력을 분리해 각각 확보한다.
- 단점: 확장 실험이 여력에 따라 수행되지 않을 수 있다.
