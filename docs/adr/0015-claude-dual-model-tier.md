# ADR-015: LLM은 Claude 단일 제공자를 쓰되 생성(소형)과 채점·에이전트(중형)의 모델 등급을 분리한다

| 항목 | 값 |
| --- | --- |
| **상태** | 수락됨 |
| **날짜** | 2026-10-20 |
| **작성자** | `BOTH` |
| **검토자** | `AI-SVC`, `AI-MDL` |

---

## 컨텍스트

LLM은 세 곳에서 쓰인다. RAG 응답 생성, 2단계 채점, 원인 분석 에이전트 추론이다. 생성과 채점에 같은 모델을 쓰면 자기 선호 편향(self-preference bias)이 개입해 채점 결과의 신뢰도가 떨어진다. 한편 기관에는 Claude API Key만 요청해 둔 상태이고, 예산은 LLM 호출이 가장 큰 비중을 차지한다.

## 결정 근거

- 자기 선호 편향 통제.
- 예산 통제 가능성(기관 지원 범위).
- 채점 품질.
- 편향 통제 근거를 논문·발표에서 방어할 수 있는지.

## 고려한 옵션들

- 옵션 1: 생성·채점 모두 동일 모델
- 옵션 2: 생성과 채점을 서로 다른 제공자로 분리
- 옵션 3: Claude 단일 제공자 + 등급 분리(생성 소형 / 채점·에이전트 중형) + 표본 교차 검증

## 결정

옵션 3 **단일 제공자 + 등급 분리 + 교차 검증**을 선택한다. 기관 지원 키로 비용을 통제하면서도 등급 분리로 자기 선호 편향을 상당 부분 완화할 수 있고, 남는 편향 우려는 2단계 채점 결과 중 100~200건을 다른 제공자의 채점자로 재채점해 일치도를 함께 보고하는 방식으로 방어할 수 있다. "모델 교체" 주입 시나리오에서도 채점 모델과 같은 모델로 바꾸지 않아 분리를 유지한다.

## 결과

**긍정적**

- 생성·채점 분리로 채점 신뢰도 검증(과제 B)의 전제가 성립한다.
- 단일 제공자라 키 관리와 비용 추적이 단순하다.
- 교차 검증 표본으로 한계를 수치로 보고할 수 있다.

**부정적**

- 제공자 간 채점 성향 비교는 본 실험으로 수행하지 못한다.
- 제공자 장애나 모델 폐기가 전체 파이프라인에 영향을 준다.

**후속 작업**

- LLM 호출을 제공자 독립 인터페이스로 감싸기
- 교차 검증용 타 제공자 키(소액) 확보 — 기관 지원 회신 이후
- 채점 모델·채점 프롬프트도 버전으로 기록

## 옵션별 장단점

### 옵션 1 — 동일 모델

- 장점: 구성이 가장 단순하고 비용이 낮다.
- 단점: 자기 선호 편향을 통제할 수단이 전혀 없어 채점 결과를 방어할 수 없다.

### 옵션 2 — 제공자 분리

- 장점: 편향 통제 근거가 가장 강하다.
- 단점: 기관 지원 범위를 벗어나 예산·키 확보가 불확실하다.

### 옵션 3 — 단일 제공자 + 등급 분리 (채택)

- 장점: 예산 통제와 편향 완화를 동시에 얻고, 표본 교차 검증으로 한계를 보완한다.
- 단점: 제공자 종속이 남는다.
